The comb

Six cells, one protocol.

A task is a cell: it is opened, filled, sealed. What a caller may do to it is the protocol's, not the agent's, so the same six cells answer for every agent built on this library.

01

The card

What the agent is, which interfaces it answers on, what it can be asked to do. Served at a well-known address, before anything else is said.

GET /.well-known/agent-card.json
02

A task

The first thing an agent says about a piece of work opens its task. History, artifacts and the current state live there, not in the agent.

SendMessage · GetTask · ListTasks
03

A stream

Every event as it happens, one frame each, in the order the agent took them. A caller that arrives late starts at the task and follows what comes next.

SendStreamingMessage · SubscribeToTask
04

A webhook

A caller leaves a URL and the agent posts each update to it, carrying the token and the credentials the registration named.

CreateTaskPushNotificationConfig
05

A stop

A task that has finished takes no more messages, and one that cannot stop says why. Both are refusals with the specification's own codes.

CancelTask · TaskNotCancelable
06

A refusal

Nine errors, each with the code section 5.4 assigns and a google.rpc.ErrorInfo detail, so a client can branch on the reason rather than on the sentence.

-32001 … -32009
The wire

JSON-RPC, and nothing else.

One POST body carries a call; a streaming method answers with server-sent events, each one a whole JSON-RPC reply. What you see below is what this library writes.

  • Every call is JSON-RPC 2.0: one request, one answer, and for a stream, one answer per event.
  • The stream opens with the task as it stands, then carries what changed, and closes at a terminal state.
  • A call refused before the stream opens is a plain error body, not a stream carrying one error.

Start

An agent is an executor.

Say what happens; the server turns it into a task, keeps the history, answers the protocol around it, and hands the same events to every watcher.

hello.mbt
impl @moona2a.Executor for Echo with fn execute(self, ctx, out) {
  ignore(self)
  out.emit(ctx.status(@moona2a.Working))
  out.emit(ctx.artifact(@moona2a.Artifact::text("a-1", "done")))
  out.emit(ctx.status(@moona2a.Completed))
}

let server = @moona2a.Server::new(Echo::{ }, card)
let app = @asgi.to_asgi(server)
