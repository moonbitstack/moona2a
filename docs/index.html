Serve it, or call it. One library, both ends of the same conversation.

01
What it is

A protocol, and both of its ends.

An agent that other agents can talk to needs a document saying what it is, one endpoint answering a fixed set of methods, and a way to report work that takes longer than a request.

01

One address per agent

The card is served at a well-known path and lists the interfaces the agent answers on. Every method is a POST to that one address, so a caller needs nothing else to begin.

02

A task, not a request

The first thing an agent says about a piece of work opens its task. History, artifacts and state live in the task, so a caller that arrives late can read what it missed.

03

Streams that can be joined

A streaming call reports every event as it happens. A caller that arrives later subscribes to the running task, is given the task as it stands, then follows what comes next.

04

No socket of its own

The server is an ASGI application, so the HTTP server stays a choice the host makes. The client talks through a transport trait, so a test and a live agent carry the same calls.

02
The methods

Eleven calls, one path.

Everything an agent can be asked is one of these eleven. Six answer once, two answer with a stream, three keep the bookkeeping for a task someone else is watching.

03
The task

Eight states, four of them final.

Once a task is completed, failed, canceled or rejected, no message, cancellation or transition applies to it again. Up to that point it may wait on the caller as readily as it works.

SUBMITTEDAccepted, not yet picked up.
WORKINGThe agent is running it.
INPUT_REQUIREDWaiting on the caller.
AUTH_REQUIREDWaiting on credentials.
COMPLETEDFinished, with a result.
FAILEDThe run raised.
CANCELEDStopped on request.
REJECTEDRefused before it ran.
may still move terminal

05
Telemetry

Every run,
on the record.

An agent run and a caller's call are spans in the OpenTelemetry GenAI conventions: invoke_agent and the agent's name, with the task, its state and the method beside them. The tracer is the one the process already runs.

  • The span opens when the agent is handed the message and closes when it stops emitting, so its length is the run.
  • Every status change and every artifact is an event inside the span, at the time it happened.
  • Message text is left out until recording_content() asks for it; at_most(n) caps what one record can cost.
  • A call carries its trace across the wire, so the run on the other side is a child of the span that called it.
  • The spans are checked against the conventions by weaver registry live-check in CI, with the example server sending them for real.
trace.mbt
let tracing = @otel.Tracing::new(
  tracer=@trace.Tracer::new(rand=entropy, sink=exporter, sampler=@trace.always),
  now=nanoseconds,
  agent=@otel.Agent::of_card(card),

06
Refusals

Nine ways to be told no.

Each refusal carries the code the specification assigns it and an ErrorInfo detail, so a client branches on the reason rather than on the sentence.

-32001TaskNotFoundNo task under that id.
-32002TaskNotCancelableIt is finished, or it cannot stop.
-32003PushNotificationNotSupportedThe agent takes no webhooks.
-32004UnsupportedOperationThe method, or a task that is over.
-32005ContentTypeNotSupportedA part the agent cannot read.
-32006InvalidAgentResponseThe agent answered with something else.
-32007ExtendedAgentCardNotConfiguredThere is no second card.
-32008ExtensionSupportRequiredAn extension the caller must honour.
-32009VersionNotSupportedA version this interface does not speak.
07
Ten lines

An agent, and a server.

Four packages arrive together: the wire model and the client, the ASGI endpoint, the client's HTTP transport with the webhook notifier, and the instrumentation.

  • A streaming answer is one JSON-RPC reply per event, written as the event happens.
  • A task that raises still lands in FAILED, so no watcher is left waiting on a task that will not move.
  • The next step is the guide: a card, a server, a client, a stream.
  • Every public type and function is in the reference, generated from the sources.
hello.mbt
impl @moona2a.Executor for Echo with fn execute(self, ctx, out) {
  ignore(self)
  out.emit(ctx.status(@moona2a.Working))
  out.emit(ctx.artifact(@moona2a.Artifact::text("a-1", "done")))
  out.emit(ctx.status(@moona2a.Completed))
}

let server = @moona2a.Server::new(Echo::{ }, card)
let app = @asgi.to_asgi(server)
