The star

Six agents, one task.

A hub convenes five spokes; each spoke is an agent with one skill. Pick a spoke, send it a line, and read the frame this library encodes: the call, the task, and every update after it. Nothing on this page is a picture of a protocol — the JSON comes from the library, compiled to JavaScript.
